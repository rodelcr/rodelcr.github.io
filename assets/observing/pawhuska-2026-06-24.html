Public Observing Itinerary — Pawhuska, OK — Night of 2026-06-24 (into 06-25)

Context

Public outreach night with a Cassegrain, ~360° horizon, starting 9pm CDT. Goal: bright, eye-pleasing point sources (planets + double/colored stars), plus the Moon and globulars (which resolve to pinpoint stars in a Cassegrain). No galaxies/nebulae — and an 80%-lit Moon would wash those out anyway, so the sky cooperates with this plan.

All alt/az computed with astropy (builtin ephemeris) for lat 36.67°N, lon −96.33°W. CDT = UTC−5.

Sky conditions tonight

  • Twilight: Sun −3° at 9pm (civil); astronomical dark (Sun < −18°) ≈ 10:45pm. → 9:00–10:45 = bright-object / twilight window; deep-dark targets after.
  • Moon: ~80% waxing gibbous. 33° alt, due S at 9pm → sinks to SW, 16° by 1am. Showpiece terminator/crater detail. Hit it before it gets low.
  • Planets are all early & low in the WEST and set fast — open with them.
  • Saturn doesn’t rise until ~2am — skip (outside the public window).

NexStar setup & alignment — DO THIS FIRST

Site / time entry: Pawhuska, OK — lat 36.67° N, lon 96.33° W; time zone Central, DST ON, date 2026-06-24. Level the tripod and set the tube to the index / home marks before aligning. When centering any align or GoTo object, always finish the move with the Up + Right buttons to take out gear backlash.

Two-stage alignment for tonight (it’s still twilight at 9pm, so few stars yet):

  1. 9:00pm — Solar System Align on the Moon (or Venus). One bright object is enough; gets the mount tracking immediately so you can show the setting planets right away. ALIGN > Solar System Align > Moon
  2. ~9:45–10pm (4+ stars out) — redo a full-sky align for accurate GoTo all night:
    • SkyAlign (easiest with a crowd): center any 3 bright objects; no need to name them — the Moon and bright stars all qualify. ALIGN > SkyAlign
    • Auto Two-Star Align (most accurate): pick one named star, scope picks the second. ALIGN > Auto Two-Star Align
    Good, well-separated align stars up tonight: Arcturus (high S), Vega (high NE), Altair (rising E later), Spica / Regulus (W). Pick two on opposite sides of the sky, >40° apart; avoid the zenith and avoid Polaris as an align star.

Quick pointing cheat-sheet (by direction, for a 360° site)

  • W / WNW (early only): Venus → Jupiter → Mercury (set by ~10:30).
  • S: Moon, Arcturus, Antares/Scorpius, M5.
  • Overhead/NE: Vega, Epsilon Lyrae, Izar, M13, M92, Albireo.
  • N: Polaris (fixed at 36°), Mizar/Alcor (NW, high).
  • SE (late): M22 climbing.

Verification / day-of check

  • Re-run scratchpad/obs.py day-of to confirm (positions are stable, but good practice). Adjust block times if your actual start slips.
  • Weather/seeing: low-west planets (Venus/Jupiter at 12–26°) need a clear WNW horizon — confirm no tree line / haze there at the site.
  • If clouds delay start past ~10:30pm, you lose the planets; pivot straight to Block C (doubles + globulars near zenith, unaffected).
